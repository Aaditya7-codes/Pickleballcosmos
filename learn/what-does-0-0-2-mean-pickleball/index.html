What Does 0-0-2 Mean in Pickleball?

Traditional doubles pickleball starts at 0-0-2. The first zero is the serving team’s score, the second zero is the receiving team’s score, and the 2 means the opening server is treated as the second server of that service turn.

By Pickleball Cosmos EditorialUpdated August 13, 2026
The ruling: 0-0-2 is not a countdown, a player ranking or a permanent server number. It is the opening score call used in traditional doubles side-out scoring because the team that serves first receives only one service opportunity before the first side out.

Read 0-0-2 from left to right

NumberMeaning at the start of the game
0The serving team has zero points.
0The receiving team has zero points.
2The opening server is designated server 2 for this opening service turn.

That same three-part structure is used throughout traditional doubles: serving team’s score → receiving team’s score → server number. A call of 7-4-1 therefore means the serving team has seven points, the receiving team has four, and server 1 is serving.

Why does the first team start on server 2?

During a normal doubles service turn, both partners can get a chance to serve. Server 1 serves until that team loses a rally; the partner then serves as server 2. When server 2 loses a rally, the opponents gain the serve.

The opening service turn is the exception. USA Pickleball gives the team that starts the game only one server before side out. That limits the initial serving advantage. Because there is no first-server turn before that opening player loses serve, the opening player is designated server 2.

The 2 is not tied permanently to one player

Server 1 and server 2 describe the team’s current service sequence. They are not permanent identities assigned to the two partners for the entire game.

After a side out, the player positioned on the right according to the team’s score becomes the first server for that new service turn. Depending on how the players have moved through the game, that can be either partner.

Useful mental model: the third number answers “which service chance is this team using right now?” It does not answer “which player is this forever?”

What happens after 0-0-2?

RallyNext situation
Opening serving team winsIt scores a point. The same server switches service courts and continues, now at 1-0-2.
Opening serving team then losesImmediate side out because the opening server is already designated server 2.
Receiving team gains serveIts normal two-server service sequence begins with server 1.

Suppose Team A starts at 0-0-2, wins the first rally, then loses the next. Team A reaches 1-0-2 and then sides out. Team B begins its service turn at 0-1-1: Team B has zero, Team A has one, and Team B’s first server is serving.

Why not start at 0-0-1?

Because 0-0-1 would imply that the opening team still has its second server waiting after the first server loses a rally. It does not. The opening service turn contains only one service opportunity.

The 2 is therefore a compact way to preserve the normal doubles scoring logic while encoding the first-server exception.

USA Pickleball considered changing 0-0-2 for 2026

A 2026 rule proposal asked USA Pickleball to replace the traditional 0-0-2 opening call with 0-0-0. The Board disapproved the proposal. The 0-0-2 convention therefore remains part of traditional doubles scoring in 2026.

Does rally scoring start at 0-0-2?

No. The 0-0-2 convention belongs to traditional doubles side-out scoring. USA Pickleball also provisionally allows rally scoring in specified tournament formats, and that system uses a different service structure.

Quick answers

What do the three numbers mean in pickleball?

In traditional doubles, they are the serving team’s score, the receiving team’s score and the current server number.

Why is the first serve 0-0-2?

The first serving team gets only one server on the opening service turn, so the opening player is designated server 2.

Is the same player always server 2?

No. Server 1 and server 2 reset with each service turn.

Do singles games start at 0-0-2?

No. Traditional singles has no third server number because there is no partner.
