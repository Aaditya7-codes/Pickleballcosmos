What Does 0-0-2 Mean in Pickleball?

Traditional doubles starts at 0-0-2: serving team score, receiving team score, then the server number. The opening server is designated server 2 because the team that serves first gets only one service opportunity before the first side out.

By Pickleball Cosmos EditorialUpdated August 13, 2026
The ruling: the “2” is not a player ranking or a permanent identity. It marks the second-server position in that opening service sequence.

Read 0-0-2 from left to right

NumberMeaning
0The serving team has zero points.
0The receiving team has zero points.
2The opening server is designated server 2 for the first service turn.

The same three-part order applies throughout traditional doubles: serving score → receiving score → server number. A call of 7-4-1 means the serving team has seven, the receiving team has four, and server 1 is serving.

Why does the first team start on server 2?

Normally, both partners can serve before a side out. The opening service turn is the exception: only one player on the team that starts the game gets to serve. When that player loses the rally, service passes immediately to the opponents.

Designating that opening player as server 2 preserves the normal doubles sequence: a loss by server 2 produces side out.

Server numbers are not permanent

“Server 1” and “Server 2” apply to the current service turn, not to fixed players for the whole game. After a side out, the player correctly positioned on the right becomes the first server for the new service turn. That can be either partner depending on the score and positions.

A short example

MomentCallMeaning
Opening serve0-0-2Team A begins with its only server in the opening service turn.
Team A wins1-0-2Team A scores; the same server switches sides and continues.
Team A then losesSide outTeam B gains serve immediately.
Team B begins0-1-1Team B starts its normal two-server service turn with server 1.

Why not 0-0-1—or 0-0-0?

Starting at 0-0-1 would imply that another server remains after the opening server loses, which is not true. USA Pickleball also considered a 2026 proposal to replace 0-0-2 with 0-0-0; the Board disapproved it. Traditional doubles therefore continues to start at 0-0-2.

Does rally scoring use 0-0-2?

No. The 0-0-2 convention belongs to traditional doubles side-out scoring. USA Pickleball’s provisional rally-scoring format uses a different service and scoring structure.

Quick answers

Why are there three numbers in doubles pickleball?

The first two are the team scores; the third is the current server number.

Is one player always server 2?

No. Server numbers reset with each service turn.

Does singles start at 0-0-2?

No. Traditional singles uses two numbers because there is no second partner/server number.
