Pickleball Scoring 2026: Why 0–0–2 Makes Sense

Traditional pickleball uses side-out scoring: only the serving side scores. In doubles, the three-number call tracks the two team scores and which server is serving. The awkward-looking 0–0–2 opening score exists for one specific reason.

By Pickleball Cosmos EditorialUpdated August 10, 2026
The short version: in traditional doubles scoring, call the serving team’s score, the receiving team’s score, then the server number. So 6–4–1 means the serving team has 6, the receiving team has 4, and server 1 is serving. A game begins at 0–0–2 because the team that serves first gets only one server before the first side out.

Traditional side-out scoring is still the baseline system

Under USA Pickleball’s traditional side-out system, a point is scored only when the serving player or team wins the rally. If the receiving side wins the rally, it wins the serve or advances the serving sequence, but it does not score a point.

USA Pickleball also provisionally permits rally scoring in specified tournament formats. That is a different scoring system, so players should check the event format instead of assuming every sanctioned match uses traditional side-out scoring.

Doubles scores have three numbers

Score callMeaning
4–2–1Serving team has 4, receiving team has 2, server 1 is serving
4–2–2Serving team has 4, receiving team has 2, server 2 is serving
0–0–2Opening score: both teams have 0, and the opening server is designated server 2 because the starting team gets only one server before the first side out

The order is always: serving team’s score → receiving team’s score → server number.

Why does doubles start at 0–0–2?

Normally, both partners on a doubles team get an opportunity to serve before the serve passes to the opponents. The team that starts the game is the exception: only one partner serves during the opening service turn.

Because the opening team has only one service opportunity before the first side out, the opening server is designated server 2. That is why traditional doubles begins at 0–0–2, not 0–0–1.

What the “2” does not mean: it is not a permanent player number. It identifies the second-server position in that service sequence.

Server 1 and server 2 are not permanent identities

A player is not permanently “server 1” or “server 2” for the entire game. The third number describes where the serving team is within its current service turn. When the team later regains serve, who serves first depends on the team’s score and positions.

How a normal doubles service turn works

What happensScoring consequence
Server 1 wins the rallyServing team scores; same server switches sides and serves again
Server 1 loses the rallyNo point; partner becomes server 2
Server 2 wins the rallyServing team scores; same server switches sides and serves again
Server 2 loses the rallyNo point; side out and opponents gain the serve

The opening service turn is the special case: there is no first-server opportunity before the opening server loses serve, so that loss produces an immediate side out.

The serving team switches sides only when it scores

In traditional doubles scoring, when the serving team wins a rally, it scores a point and the server switches service courts before serving again. The receiving team does not switch merely because it won a rally.

A useful positioning check follows from the team score: when a team’s score is even, the player who began the game on the right should be on the right; when it is odd, that player should be on the left.

Singles scoring is simpler

Traditional singles uses two numbers: the server’s score followed by the receiver’s score. There is no third server number because there is no partner.

Even server score = serve from the right. Odd server score = serve from the left.

How many points do you play to?

Standard games are commonly played to 11 points, win by 2. Approved tournament formats may also use games to 15 or 21, win by 2. Tournament directors can choose among permitted match formats, so the event instructions control.

Rally scoring in 2026: every rally can score, including game point

Under the 2026 provisional rally-scoring rule, a point is scored by the singles player or doubles team that wins each rally. The winner of the rally scores regardless of which side served.

That includes the final point. USA Pickleball approved a 2026 change removing the older game-point restriction that had required the winning point to be scored while serving. If a team is at game point while receiving and wins the rally, it scores the point and can win the game.

This is an important source-quality issue because older USA Pickleball educational material may still describe the previous provisional system. For 2026, Pickleball Cosmos follows the current Official Rulebook and approved 2026 rule-change record.

Quick answers

Why are there three numbers in doubles pickleball?

The first two are the team scores. The third identifies server 1 or server 2 in the serving team’s current service turn.

Why does pickleball start at 0–0–2?

Because the team serving first receives only one server during the opening service turn.

Can the receiving team score?

Not under traditional side-out scoring. Under the 2026 provisional rally-scoring option, the winner of every rally scores, including at game point.

Do you have to win by two?

Yes for the standard game formats discussed here.

Is one player always server 1?

No. Server number is not a permanent identity.
