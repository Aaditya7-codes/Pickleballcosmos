Pickleball Scoring 2026: Why 0–0–2 Makes Sense

Traditional pickleball uses side-out scoring: only the serving side scores. In doubles, the three-number call tracks the two team scores and which server is serving. The awkward-looking 0–0–2 opening score exists for one specific reason.

By Pickleball Cosmos EditorialUpdated August 10, 2026
The short version: in traditional doubles scoring, call the serving team’s score, the receiving team’s score, then the server number. So 6–4–1 means the serving team has 6, the receiving team has 4, and the first server of that service turn is serving. A game begins at 0–0–2 because the team that serves first gets only one server before the first side out.

Traditional side-out scoring is still the baseline system

Under USA Pickleball’s traditional side-out system, a point is scored only when the serving player or team wins the rally. If the receiving side wins the rally, it wins the serve or advances the serving sequence, but it does not score a point.

USA Pickleball continues to describe traditional side-out scoring as the official method, while also provisionally allowing rally scoring in specified tournament formats. That distinction matters in 2026 because not every sanctioned event necessarily uses the same scoring option.

Doubles scores have three numbers

Score callMeaning
4–2–1Serving team has 4, receiving team has 2, first server of the current service turn is serving
4–2–2Serving team has 4, receiving team has 2, second server of the current service turn is serving
0–0–2Opening score: both teams have 0, and the opening server is designated as server 2 because the starting team gets only one server before the first side out

The order is always:

  1. Serving team’s score
  2. Receiving team’s score
  3. Server number: 1 or 2

Why does doubles start at 0–0–2?

Normally, both partners on a doubles team get an opportunity to serve before the serve passes to the opponents. The team that starts the game is the exception: only one partner serves during the opening service turn.

USA Pickleball’s explanation is straightforward: this reduces the advantage of getting the first serve. Because the opening team has only one service opportunity before the first side out, the opening server is designated as server 2. That is why the game starts at 0–0–2, not 0–0–1.

What the “2” does not mean: it does not mean player No. 2 on the team, the second point of the game, or the player standing on a particular side forever. It identifies the second-server position in that service sequence.

Server 1 and server 2 are not permanent identities

This is one of the most common beginner mistakes. In doubles, a player is not permanently “server 1” or “server 2” for the entire game.

The server number tells you where you are within the team’s current service turn. When that team later regains the serve, the identity of the first person serving can depend on the team’s score and court positions. USA Pickleball specifically warns that beginners often assume a player keeps the same server number throughout the game; that assumption is wrong.

How a normal doubles service turn works

What happensScoring consequence
Server 1 wins the rallyServing team scores a point; same server switches sides and serves again
Server 1 loses the rallyNo point; partner becomes server 2
Server 2 wins the rallyServing team scores a point; same server switches sides and serves again
Server 2 loses the rallyNo point; side out and opponents gain the serve

The opening service turn is the special case: there is no first-server opportunity before the opening server loses serve, so that loss produces an immediate side out.

The serving team switches sides only when it scores

In traditional doubles scoring, when the serving team wins a rally, it scores a point and the server switches from one service court to the other before serving again. The receiving team does not switch sides merely because it won a rally.

This movement creates an important positioning check. USA Pickleball states that when a team’s score is even, the player who began the game as that team’s first server should be on the right side; when the score is odd, that player should be on the left. If that relationship is wrong, either the score or the positions are wrong.

A full doubles example

Suppose Team A begins the game.

Once you understand that sequence, the third number becomes bookkeeping rather than mystery.

Singles scoring is simpler

Traditional singles uses only two numbers: the server’s score followed by the receiver’s score. There is no third server number because there is no partner.

Serving position is tied to the server’s score:

  • Even score: serve from the right side.
  • Odd score: serve from the left side.

The core side-out principle is unchanged: under traditional singles scoring, only the server can score a point.

How many points do you play to?

USA Pickleball’s rules summary says games are normally played to 11 points, win by 2. Tournament formats may instead use games to 15 or 21, also win by 2. Approved sanctioned formats can vary by bracket and match structure, so players should check the tournament format rather than assuming every match is one game to 11.

Rally scoring exists in 2026 — but it is not the same system

Rally scoring awards a point after every rally, regardless of which side served. USA Pickleball provisionally recognizes rally scoring for specified tournament formats, while traditional side-out scoring remains the baseline method and continues to be used for major USA Pickleball events such as Golden Ticket tournaments and Nationals.

The differences go beyond simply awarding more points. Rally scoring changes service-sequence logic as well. For example, USA Pickleball’s rally-scoring guidance says there is no second server in the same sense as traditional doubles side-out scoring, and the starting score is therefore 0–0 rather than 0–0–2.

Quick answers

Why are there three numbers in doubles pickleball?

The first two are the team scores. The third identifies whether server 1 or server 2 is serving during the serving team’s current service turn.

Why does pickleball start at 0–0–2?

Because the team serving first receives only one server during the opening service turn. That opening server is designated server 2 so that losing the rally produces an immediate side out.

Can the receiving team score?

Not under traditional side-out scoring. Under the provisional rally-scoring option, the winner of each rally scores regardless of who served.

Do you have to win by two?

Yes for the standard USA Pickleball game formats discussed here. Games are commonly to 11 and may be to 15 or 21, with a two-point winning margin.

Is one player always server 1?

No. Server number is not a permanent identity assigned to one partner for the entire game.
